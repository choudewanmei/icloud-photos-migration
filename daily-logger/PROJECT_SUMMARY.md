# 📝 每日记录工具 - 项目总结

## 🎯 项目目标

开发一个简单易用的命令行工具，帮助用户：
- 记录每日活动
- 分类管理记录
- 统计分析时间分配
- 导出数据备份

## ✨ 核心功能

### 1. 记录管理
- ✅ 添加记录（支持分类、标签、时长、优先级）
- ✅ 查看记录（支持按时间、分类、标签筛选）
- ✅ 删除记录
- ✅ 搜索记录

### 2. 分类系统
- ✅ 8 个预设分类（工作、学习、生活、运动、娱乐、社交、创作、其他）
- ✅ 支持自定义分类
- ✅ 分类图标和颜色

### 3. 标签系统
- ✅ 支持多标签（逗号分隔）
- ✅ 按标签筛选
- ✅ 热门标签统计

### 4. 统计分析
- ✅ 总体统计（记录数、总时长）
- ✅ 分类统计
- ✅ 每日统计
- ✅ 本周/本月统计
- ✅ 今日总结

### 5. 数据导出
- ✅ JSON 格式导出
- ✅ CSV 格式导出（可用 Excel 打开）
- ✅ 支持按时间范围导出

## 🚀 快速开始

```bash
# 进入工具目录
cd daily-logger

# 添加第一条记录
./log add "开始使用每日记录工具" -c 其他 -t 工具

# 查看记录
./log list

# 查看今日总结
./log today
```

## 📊 命令速查表

| 命令 | 说明 | 示例 |
|------|------|------|
| `add` | 添加记录 | `./log add "内容" -c 分类 -t 标签 -d 时长` |
| `list` | 查看记录 | `./log list -d 7 -c 工作` |
| `today` | 今日总结 | `./log today` |
| `stats` | 统计信息 | `./log stats -d 30` |
| `search` | 搜索记录 | `./log search "关键词"` |
| `categories` | 查看分类 | `./log categories` |
| `delete` | 删除记录 | `./log delete 123` |
| `export` | 导出数据 | `./log export json file.json` |

## 🔧 技术实现

### 数据库设计

# 📝 每日记录工具

一个简单易用的命令行工具，用于记录你的日常活动并进行统计分析。

## ✨ 功能特性

- 📝 **记录活动** - 快速记录你做了什么
- 📂 **分类管理** - 支持多种预设分类（工作、学习、生活等）
- 🏷️ **标签系统** - 使用标签更灵活地组织记录
- ⏱️ **时间追踪** - 记录每项活动的时长
- 📊 **统计分析** - 查看详细的数据统计
- 🔍 **搜索功能** - 快速找到历史记录
- 📤 **数据导出** - 支持 JSON 和 CSV 格式导出

## 🚀 快速开始

### 添加记录

```bash
# 基本记录
./log add "完成了项目报告"

# 带分类记录
./log add "学习 Python 编程" -c 学习

# 带标签和时长记录
./log add "写周报" -c 工作 -t 周报,汇报 -d 30

# 重要记录
./log add "完成项目演示" -c 工作 -p 1
```

### 查看记录

```bash
# 查看最近记录
./log list

# 查看最近 7 天的记录
./log list -d 7

# 按分类筛选
./log list -c 工作

# 按标签筛选
./log list -t 项目
```

### 统计信息

```bash
# 查看总体统计
./log stats

# 查看最近 30 天统计
./log stats -d 30

# 查看今日总结
./log today
```

### 搜索记录

```bash
./log search "项目"
```

### 导出数据

```bash
# 导出为 JSON
./log export json backup.json

# 导出为 CSV
./log export csv backup.csv

# 导出最近 30 天数据
./log export json month.json -d 30
```

### 管理记录

```bash
# 查看所有分类
./log categories

# 删除记录（使用记录 ID）
./log delete 123
```

## 💡 使用技巧

1. **使用标签**：用逗号分隔多个标签，如 `-t 项目,汇报,重要`
2. **记录时长**：使用 `-d` 参数记录活动时长（分钟）
3. **标记重要**：使用 `-p 1` 标记重要事项
4. **每日回顾**：使用 `./log today` 查看今日总结
5. **定期导出**：定期导出数据进行备份

## 📁 文件说明

- `enhanced_logger.py` - 主程序
- `log` - 快捷启动脚本
- `daily_logger.db` - 数据库文件（自动创建）

## 🔧 高级用法

### 组合查询

```bash
# 查看最近 7 天工作分类的记录
./log list -d 7 -c 工作

# 查看包含"项目"标签的重要记录
./log search "项目"
```

### 数据分析

```bash
# 查看本周统计
./log stats -d 7

# 查看本月统计
./log stats -d 30
```

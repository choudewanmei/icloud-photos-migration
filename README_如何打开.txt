============================================================

📁 项目位置:
/Users/louise/Documents/iCloud照片迁移助手

🚀 如何打开应用:

方式一：双击 .command 脚本（推荐）
────────────────────────────────
1. 打开 Finder
2. 进入文件夹: iCloud照片迁移助手
3. 双击: iCloud照片迁移助手.command
4. 应用会自动启动

方式二：双击 .app 应用
────────────────────────────────
1. 打开 Finder
2. 进入文件夹: iCloud照片迁移助手/dist
3. 双击: iCloud照片迁移助手.app
4. 应用会自动启动

方式三：终端运行
────────────────────────────────
1. 打开终端
2. 输入: cd /Users/louise/Documents/iCloud照片迁移助手
3. 输入: python3 main.py

📤 如何分享给其他人:

1. 复制整个文件夹: iCloud照片迁移助手
2. 发送给其他人
3. 对方按照上述方式打开即可

⚠️ 首次运行可能需要:

1. 安装依赖:
   pip3 install -r requirements.txt

2. macOS 安全提示:
   - 右键点击文件 → 选择「打开」
   - 或者: 系统偏好设置 → 安全性与隐私 → 允许运行
